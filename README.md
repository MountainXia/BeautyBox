# 妆匣 BeautyBox（V2.0）

**妆匣 BeautyBox** 是一款面向个人的 **本地优先、无账号、可自主备份** 的 iPhone 原生美妆资产管理与妆容记录应用，帮助用户管理拥有的美妆产品、购买/开封/到期信息、妆容照片、实际使用的产品实例与持妆体验。

> 核心原则：无注册登录墙、数据默认保存在本机 App 私有空间、核心功能完全离线可用、iCloud 备份默认关闭且仅由用户主动触发、订阅到期不锁定或删除已有数据。

---

## 核心功能概览

- **首页**：持有件数、累计购买金额、临期提醒、分类分布、最近妆容与快捷新增。
- **妆匣**：产品主档案（`Product`）与实际持有实例（`ProductItem`）分离管理，支持多瓶/多批次独立记录购买信息、开封日期、PAO、系统推算与人工确认到期日、剩余量与归档。
- **妆容与持妆**：记录妆容照片、耗时、风格/场景与自评，关联真实使用的 `ProductItem` 并保留历史快照；支持刚完成及 2/4/6/8 小时或自定义时间点的持妆照片与主观表现追踪。
- **日常**：产品使用日志、早晚/每周/自定义护肤流程与主观肌肤日记（仅作个人记录，不构成医疗诊断）。
- **数据管理与分享**：支持本地自动保存、`.beautyboxbackup` 一致性备份与安全点恢复（iCloud 默认关闭）、JSON/CSV 与照片 ZIP 导出（对免费用户开放），以及脱敏字段可控的分享图片生成。
- **会员订阅**：基于 StoreKit 2 提供购买、恢复购买与状态管理，无需自建账号。

## 开发环境与工作流说明

- **目标平台与技术栈**：iOS 原生（Swift + SwiftUI，Feature 模块化 + MVVM + Repository），本地存储优先评估 SQLite + GRDB（或经验证的 SwiftData），内购使用 StoreKit 2。
- **当前前期开发阶段（Windows / Linux + iPhone）**：
  - 可在本机完成：需求与 ADR 固化、浏览器可点击原型（供 iPhone Safari 测试）、SQLite Schema 与迁移脚本设计、自动化逻辑与数据校验测试、Swift 源码编写。
  - **环境限制**：Windows / Linux 环境无 Apple Xcode、iOS Simulator 与代码签名工具链，无法在本机执行 iOS 工程编译、Archive 打包、StoreKit 沙盒及 iCloud 实测。
- **后期构建与发布阶段（Mac / Xcode）**：
  - 原生工程构建、模拟器与真机调试、iCloud Drive / StoreKit 2 沙盒实测、TestFlight 分发与 App Store 上架均需在 Mac / Xcode 环境中完成。
