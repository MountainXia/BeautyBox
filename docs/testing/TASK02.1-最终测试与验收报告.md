## 3. 人工真机验收建议步骤（iPhone Safari）

1. 推送并等待 GitHub Pages 部署完成后，在 Safari 强制刷新 `https://mountainxia.github.io/BeautyBox/`。
2. 检查手机顶部时钟/信号安全区与「我的美妆」顶栏之间不再出现灰白分界线。
3. 在 Safari 分享菜单点击「添加到主屏幕」，确认图标已更换为妆匣新图标（源自 `beautybox-source.png`）。
4. 点击「+ 添加产品」，确认「规格单位」仅含 `不填 / ml / g / 其他（自定义）`，并测试先填生产日期后再选开封日期时的限制。
5. 进入任意妆容详情，检查新增/编辑中的风格与场景快捷标签；打开「生成分享图片」，连续开关勾选框确认预览图无明显闪动。
6. 检查「我的 → 首页资产币种与外币录入」与「导出明细 CSV」文案。
