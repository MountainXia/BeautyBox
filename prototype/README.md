# 妆匣 BeautyBox · TASK 02 浏览器可点击交互原型

> 本目录仅用于 **TASK 02 产品流程与交互验证**，不代表正式采用 Web 架构，不连接正式 SQLite 数据库，不包含真实原生 iOS 能力。

## 一、启动本地服务

在仓库根目录执行（无需安装任何第三方依赖）：

```bash
python3 -m http.server 8088 --directory prototype --bind 0.0.0.0
```

- **PC 浏览器访问**：`http://127.0.0.1:8088`
- **iPhone Safari 访问**（确保手机与电脑处于同一局域网 Wi-Fi）：
  - 若 Linux 本机直连局域网：`http://10.77.20.82:8088`
  - 若当前 Linux 运行在 Windows WSL2 / 虚拟机中，请在 Windows PowerShell 查看宿主机局域网 IP（`ipconfig`）并在需要时配置端口转发及防火墙放行 `8088` 端口后再用手机 Safari 访问。
  - 在 iPhone Safari 中可点击底部“分享 → 添加到主屏幕”体验底部安全区与全屏效果。

## 二、建议人工验收路径

1. **无登录直达首页**：首次进入关闭轻引导后直接进入首页，核对「产品资料数」与「当前持有件数」分别统计，以及「累计购买金额」按 `CNY / USD / JPY / KWD` 分组展示（无跨币种相加）。
2. **多币种精度与拦截测试**：进入「妆匣」→ 点开任一产品 → 点击「+ 添加持有实例」：
   - 尝试在 `CNY` 输入 `12.345` 或在 `JPY` 输入 `12.5` → 验证界面拦截提示，禁止静默截断；
   - 尝试选择未配置演示币种 `EUR` → 验证提示“该币种暂不支持”，禁止保存；
   - 测试 `KWD` 输入 `12.345` → 验证保存后存储最小单位整数为 `12345`、展示为 `KD 12.345`。
3. **IndexedDB 图片持久化**：在产品详情、新建妆容或肌肤日记中上传真实本地图片后刷新页面（F5），验证图片仍正常显示；在「我的」点击「清空全部模拟数据」后确认页面呈现空状态且图片同步清理。
4. **产品封面唯一真相源 & 无封面兜底**：在产品详情页切换主封面、点击「取消封面(测兜底)」及查看「微醺柔雾单色腮红」（无照片占位卡）。
5. **有效期不猜测 & 确认值保护**：修改已确认到期日实例的开封日期/PAO，验证原「用户确认到期日」未被自动覆盖，仅出现重新确认提醒。
6. **历史妆容快照保护**：编辑任意已关联妆容的产品名称或执行归档，再到「妆容」查看「玫瑰茶棕约会妆」等历史记录，验证使用产品快照保持当时信息不变。
7. **白名单分享预览 & 会员过期不锁数据**：在妆容详情点「生成分享图」检查价格/渠道/私人备注默认不显示；在「我的」将订阅切到「订阅过期」并验证仍可查看和导出 JSON/CSV。
